# What belongs in an issue

This repository is one skill, `socratic`. It reads a repository, asks the person, and writes only the rules and skills they accept.

File an issue when that happened wrong in a session you actually ran. Say what you asked the agent to do, what it wrote or installed, and what you wanted instead.

A wish with no session behind it can wait. Put how-do-I questions in discussions: https://github.com/beelarr/socratic-harness/discussions

## What we will not take

Read .out-of-scope/ before you file. Those notes are decisions, not a backlog.

Also out of scope: a setting that only your tool needs, a branch for one harness, and a change that exists to match one person's habits. Put that in your own AGENTS.md, or fork the skill.

If an issue is too thin to judge, we will ask once. If there is no reply, we will close it.
