# Security Policy

## Supported versions

This project is under active early development. Security fixes are applied to the
latest code on `main` (and current release tags when they exist).

## Reporting a vulnerability

Please report security issues through **GitHub private vulnerability reporting**
for this repository:

1. Open the repository on GitHub.
2. Go to **Security** → **Advisories** → **Report a vulnerability**
   (or use the "Report a vulnerability" button on the Security tab).
3. Include as much detail as you can: affected package/path, impact, and steps
   to reproduce.

**Do not** open a public GitHub issue for security vulnerabilities.

We will acknowledge reports as promptly as we can and coordinate disclosure
through GitHub's private advisory workflow.
